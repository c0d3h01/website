Containerization removes the classic _\"works on my machine\"_ issue.

In this post, you package a simple Node.js and Express API into a Docker container and run it consistently across systems.

## Covered in This Post

- Writing a minimal Dockerfile
- Building and tagging container images
- Running the container locally
- Understanding exposed ports and environment variables

This is part one of a Docker series and focuses on fundamentals before moving to multi-service setups.
