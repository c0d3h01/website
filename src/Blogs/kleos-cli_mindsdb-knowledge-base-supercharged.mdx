# Kleos CLI: MindsDB Knowledge Base Supercharged - Complete Guide

In the rapidly evolving world of AI agents and unstructured data management, developers need powerful tools to simplify complex data workflows. Enter Kleos CLI - a Python-based async command-line interface that supercharges MindsDB's Knowledge Base capabilities, making intelligent data management accessible through simple SQL commands.

## What You'll Learn

- Understanding MindsDB's Knowledge Base system
- Installing and configuring Kleos CLI
- Creating and managing Knowledge Bases
- Building AI agents with semantic search
- Automating workflows with MindsDB Jobs
- Best practices for data ingestion and querying

## Prerequisites

Before we start, ensure you have:

- Python 3.8+ installed on your system
- Basic knowledge of SQL and command-line interfaces
- A Google API key (for Gemini integration)
- Docker installed (for MindsDB setup)
- Basic understanding of vector databases and embeddings

## What is Kleos CLI?

Kleos (Greek for "the enduring transmission of meaningful, wise knowledge") is a powerful CLI tool designed to streamline interactions with MindsDB's Knowledge Base system. It enables developers to:

- **Organize data by meaning**: Not just keyword matching, but semantic understanding
- **Support context-aware retrieval**: Intelligent search based on data context
- **Handle diverse data sources**: From databases to CSV files, YouTube, and HackerNews
- **Utilize advanced models**: Embedding and re-ranking models for precise results
- **Enable intelligent querying**: Meaningful data discovery through AI

## Step 1: Installation and Setup

### Install Kleos CLI

```bash
# Install via pip (coming soon)
pip install Kleos

# Or clone and install locally
git clone https://github.com/yashksaini-coder/Kleos.git
cd Kleos
pip install .
```

### Set up MindsDB

Kleos works with MindsDB's Docker extension. Create a `docker-compose.yml`:

```yaml
version: '3.8'
services:
  mindsdb:
    image: mindsdb/mindsdb:latest
    ports:
      - "47334:47334"
    environment:
      - MINDSDB_STORAGE_DIR=/mindsdb
    volumes:
      - mindsdb_data:/mindsdb
volumes:
  mindsdb_data:
```

Start MindsDB:

```bash
docker-compose up -d
```

## Step 2: Core Philosophy - SQL as AI Language

Kleos embraces MindsDB's foundational principle: using SQL as the primary language for AI development. This approach allows you to:

```sql
-- Connect to diverse data sources
```

## Step 3: Knowledge Base Management

### Creating a Knowledge Base

```bash
# Create KB with local Ollama and Google Gemini
kleos kb create gemini_ollama_kb \
  --embedding-provider ollama \
  --embedding-model nomic-embed-text \
  --reranking-provider gemini \
  --reranking-model gemini-2.0-flash \
  --google-api-key YOUR_GOOGLE_API_KEY \
  --content-columns "question,answer" \
  --metadata-columns "score"
```

### Data Ingestion

```bash
# Ingest from HackerNews with smart defaults
kleos kb ingest my_hn_kb \
  --from-hackernews stories \
  --limit 100 \
  --hn-datasource my_hackernews_data

# Custom ingestion with specific mappings
kleos kb ingest my_custom_kb \
  --from-hackernews comments \
  --hn-datasource my_hackernews_data \
  --content-column "text" \
  --metadata-map '{"comment_id":"id", "author":"by", "parent_story":"parent"}' \
  --limit 200
```

### Semantic Search

```bash
# Simple semantic search
kleos kb query my_docs_kb "recent breakthroughs in quantum computing"

# Advanced search with metadata filtering
kleos kb query product_reviews_kb "positive feedback on model X" \
  --metadata-filter '{"rating":{"$gte": 4}, "verified_purchase":true}' \
  --limit 5
```

## Step 4: AI Agents Creation

### Creating an Agent

```bash
# Create support agent with Gemini
kleos kb create-agent product_support_agent \
  --model-name gemini-2.0-flash \
  --google-api-key "GOOGLE_API_KEY" \
  --include-knowledge-bases "product_faq_kb" \
  --prompt-template "You are a helpful support agent. Answer based on: {{context}}"
```

### Querying Agents

```bash
# Interact with your agent
kleos kb query-agent product_support_agent "What is the warranty period for model X?"
```

## Step 5: AI Models and Generative Tables

### Creating AI Models

```bash
# Create a title summarizer model
kleos ai create-model title_summarizer \
  --select-data-query "SELECT title AS original_title FROM my_hackernews_data.stories WHERE score > 50 LIMIT 100" \
  --predict-column title_summary \
  --engine google \
  --prompt-template "Generate a short summary: {{original_title}}" \
  --param api_key YOUR_GOOGLE_API_KEY \

```

## Step 6: Automation with Jobs

### Creating Automated Jobs

```bash
# Daily HackerNews data update
kleos job update-hn-refresh daily_hn_data_update \
  --schedule "EVERY 1 day at 02:00"

# Custom KB update job
kleos job create nightly_kb_update \
  "INSERT INTO my_kb SELECT new_text, new_metadata FROM new_data_source LATEST;" \
  --schedule "EVERY 1 day at 03:00"
```

## Step 7: Advanced Configuration

### Environment Setup

Create a `.env` file for your configuration:

```bash
# MindsDB Configuration
MINDSDB_HOST=http://localhost:47334
MINDSDB_USER=your_username
MINDSDB_PASSWORD=your_password

# API Keys
GOOGLE_API_KEY=your_google_api_key
OPENAI_API_KEY=your_openai_api_key
OLLAMA_HOST=http://localhost:11434

# Default Settings
DEFAULT_EMBEDDING_MODEL=nomic-embed-text
DEFAULT_RERANKING_MODEL=gemini-2.0-flash
```

### Python Integration

```python
from kleos import KleosClient

# Initialize client
client = KleosClient(
    mindsdb_host="http://localhost:47334",
    google_api_key="your_api_key"
)

# Create knowledge base
kb = client.create_knowledge_base(
    name="my_kb",
    embedding_provider="ollama",
    embedding_model="nomic-embed-text",
    reranking_provider="gemini",
    reranking_model="gemini-2.0-flash"
)

# Ingest data
client.ingest_data(
    kb_name="my_kb",
    source="hackernews",
    limit=100,
    content_columns=["title", "text"],
    metadata_columns=["author", "score"]
)

# Query knowledge base
results = client.query(
    kb_name="my_kb",
    query="latest AI breakthroughs",
    metadata_filter={"score": {"$gte": 10}},
    limit=5
)
```

## Step 8: Best Practices

### Performance Optimization

```bash
# Use appropriate limits for large datasets
kleos kb ingest large_dataset \
  --batch-size 1000 \
  --limit 10000 \
  --retry-on-failure

# Optimize search with specific metadata filters
kleos kb query my_kb "machine learning" \
  --metadata-filter '{"category":"tech", "date":{"$gte":"2024-01-01"}}' \
  --limit 10
```

### Security Considerations

```python
# Secure API key management
import os
from kleos import SecureConfig

config = SecureConfig(
    google_api_key=os.getenv("GOOGLE_API_KEY"),
    encryption_key=os.getenv("ENCRYPTION_KEY")
)

# Use environment variables for sensitive data
kleos kb create-agent secure_agent \
  --model-name gemini-2.0-flash \
  --google-api-key "${GOOGLE_API_KEY}" \
  --include-knowledge-bases "public_kb"
```

## Step 10: Real-World Use Cases

### Customer Support System

```bash
# Create support KB
kleos kb create support_kb \
  --content-columns "question,answer,solution" \
  --metadata-columns "category,priority,product"

# Ingest support tickets
kleos kb ingest support_kb \
  --from-database support_db \
  --table tickets \
  --content-column "description" \

# Create support agent
kleos kb create-agent support_ai \
  --model-name gemini-2.0-flash \
  --include-knowledge-bases "support_kb" \

```

### Research and Analysis

```bash
# Create research KB for papers
kleos kb create research_papers_kb \
  --content-columns "abstract,conclusions" \

  --schedule "EVERY 1 day at 06:00"
```
